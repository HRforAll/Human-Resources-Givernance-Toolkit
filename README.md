# Human Resources Governance Toolkit

Welcome! 👋

This repository is a collection of practical ideas, frameworks and sample resources for HR Shared Services and HR Operations professionals.

Topics covered include:
- HR Shared Services Governance
- HR Service Catalogs
- Internal Controls
- KPI & SLA Dashboards
- Stakeholder Management
- Continuous Improvement
